# Code of Conduct

This project welcomes contributions from anyone. Participation comes with a simple expectation: be professional.

## Standards

- Critique code and ideas, not people.
- No harassment or personal attacks of any kind, toward anyone, for any reason.
- Keep discussions focused on the project and its technical goals.
- Assume good faith. Disagreements are normal; handle them with respect.

## Scope

This code applies to all project spaces, including issues, pull requests, discussions, and code review.

## Enforcement

Maintainers are responsible for clarifying and enforcing these standards. They may edit, remove, or reject comments, commits, issues, and pull requests that violate this code, and may temporarily or permanently ban contributors for behavior they deem inappropriate.

Maintainers have final say on all contributions and moderation decisions.

## Reporting

Report unacceptable behavior by opening an issue or contacting the maintainers directly.
